# المتطلبات الوظيفية — ميقات 2.0

> **الحالة:** مقترح، بانتظار الاعتماد. كل متطلب مربوط بفجوة (GAP) وبمعيار قبول (AT) في `docs/testing/acceptance-tests.md`.
> **القرارات المعتمدة من المالك (10/10/2026):** تبادل البيانات مع الهيئة عبر Excel (ADR-002)؛ قفل الموسم وتعدد المواسم (ADR-003)؛ الحالة الصحية مرئية للمشرفين وجميع المستخدمين (ADR-004)؛ الإعلام والتوعية داخل ميقات كمرحلة متأخرة (ADR-005)؛ قبول تسجيل خروج الجميع عند نشر المصادقة (ADR-006).

## الأدوار
| الدور | الوصف |
|---|---|
| ADMIN (مسؤول النظام) | كل شيء، بما فيه النسخ والاستعادة والمستخدمون |
| COORDINATOR (المنسق) | كل البيانات التشغيلية والاعتماد والمراسلات |
| SUPERVISOR (مشرف) | مجموعته فقط للكتابة؛ يرى الفئة الصحية للجميع (ADR-004) |
| RECEPTION / DOC_REVIEWER / DATA_ENTRY | أدوار الاستلام والتدقيق والإدخال (مقترح، تقسيم للدور الحالي بصلاحيات) |
| MEDIA (إعلام) | المرحلة 4 |
| PILGRIM (حاج) | بوابة ذاتية، بيانات نفسه فقط |
