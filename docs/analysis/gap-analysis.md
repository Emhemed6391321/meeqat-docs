# مصفوفة تحليل الفجوات — ميقات مقابل أعمال تنسيقية طرابلس (ب)

> **الحالة:** مقترح (يحتاج اعتمادًا). **المصادر:** [W] ملفات التنسيقية (المرحلة 1) · [M] شيفرة Meeqat1.1 (المرحلة 3) · [N] مستنتج.
> **المرحلة 2 (النظام السابق):** تُجوزت بقرارك؛ لم يُحلَّل نظام الهيئة ولا ميقات 1.0 كشيفرة. فجوات كانت ستظهر من نظام الهيئة (مثل الاستيراد/التصدير معه) مسجلة كـ«يحتاج استيضاحًا».
> **قيد:** الحالة مبنية على قراءة الشيفرة لا تشغيلها، ولا على النسخة المنشورة.
> **الأولوية:** حرجة / عالية / متوسطة / منخفضة · **القرار:** مقترح ما لم يُذكر خلافه.

## 3. موجود ولا يحتاج تعديلًا الآن (مبدئيًا)
نموذج الحاج العام + قارئ MRZ، الاستيراد، المجموعات والتصدير الملون، البطاقة الذكية QR، الأسطول والصعود بالمسح، المخيمات، الطبي/SOS (يحتاج فقط ربطًا بـGAP-018/019)، الأمتعة، النسخ الاحتياطي المشفر.

## 4. أسئلة للاستيضاح (تعيق اعتماد بنود)
1. **Q1:** كيف تتبادل التنسيقية البيانات مع منظومة الهيئة؟ (نقل يدوي؟ ملفات؟ ماذا يلزم لتفادي الإدخال المزدوج؟) ← GAP-025/026.
2. **Q2:** هل يُراد قفل الموسم وتعدد المواسم؟ ← GAP-030 يغيّر نموذج البيانات.
3. **Q3:** من يحق له الاطلاع على الحالة الصحية (فئة حرجة): المشرف، المنسق، الطبي؟ ← GAP-002.
4. **Q4:** هل يوافق على نقل نشاط الإعلام داخل ميقات أم يبقى خارجه؟ ← GAP-027–029.
5. **Q5:** هل يُسمح بنقل مصادقة المستخدمين لجلسة خادمية، مع الأثر على الواجهة الحالية (تسجيل خروج جميع المستخدمين عند النشر)؟
