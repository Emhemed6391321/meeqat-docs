# التصور التطويري المقترح — ميقات 2.0

> **الحالة:** مقترح. يحافظ على التقنية الحالية (ADR-007 مقترح). التفاصيل الدقيقة تُراجع قبل التنفيذ.

## 1. المبادئ
1. الموسم (`season`) محور البيانات التشغيلية (ADR-003).
2. الخادم هو مرجع الصلاحيات؛ الواجهة عرض فقط.
3. كل مخرج رسمي يُولَّد من مصدر أرقام واحد.
4. الميدان: تسجيل سريع من الجوال، يعمل دون اتصال.
5. التبادل مع الهيئة عبر Excel بقوالب قابلة للضبط (ADR-002).

## 2. الوحدات الجديدة والمعدّلة

```
[Auth/Sessions] ─► [Seasons] ─► [Pilgrims] ─┬─► [Intake: receipts, checklist, follow-ups, custody, archive]
```

## 3. بطاقات الوظائف الأساسية

### بطاقة 1 — الاستلام والتدقيق (REQ-010…016)
- **المشكلة:** عدّ يدوي للمستلم والمدخل، وتضارب الأرقام، وبلا سبب لنقص المستند.
- **المستخدمون:** استقبال، مدقق، إدخال، منسق.
- **الصلاحيات:** RECEPTION تسجّل، DOC_REVIEWER يحكم على البنود، COORDINATOR يستثني ويعتمد.
- **سير العمل:** وصول ← تسجيل استلام ← تدقيق بنود ← (ناقص: متابعة) ← إدخال ← اعتماد ← أرشفة (ظرف/حافظة) ← تسليم جواز.
- **الحالات:** `NOT_RECEIVED → RECEIVED → UNDER_REVIEW → INCOMPLETE | VERIFIED → APPROVED`.
- **القواعد:** لا اعتماد مع بند إلزامي غير مقبول؛ الاستثناء مسبب.
- **المخرجات:** لوحة يومية، قائمة المتعثرين، محضر تسليم جواز.
- **التدقيق:** كل انتقال حالة.
- **التكامل:** الأرقام الرسمية، المراسلات، البطاقة الذكية (لا تُطبع لغير المعتمد).
- **القبول:** AT-010…016.

### بطاقة 2 — الأحداث والحضور (REQ-021/022)
- **المشكلة:** كشوف حضور Excel منفصلة لكل اجتماع.
- **سير:** إنشاء حدث ← استهداف مجموعات ← مسح QR/يدوي ← تقرير.
- **الحالات:** `PLANNED → OPEN → CLOSED`.
- **القواعد:** منع تكرار الحضور (idempotency)، حضور من خارج الفئة يُعلَّم.
- **التكامل:** البطاقة الذكية، الكشف الصحي (نوع حدث)، الحملة التوعوية.
- **القبول:** AT-021.

### بطاقة 3 — الكشف الصحي (REQ-023…025)
- **المشكلة:** جدولة وتقرير ورقي، ومخاطر تكدس.
- **سير:** تعريف مراكز وفترات وسعات ← إسناد المجموعات ← حضور لحظي ← تقرير المشرف ← تصحيحات بيانات.
- **القواعد:** السعة، عدم تغيير المركز بلا إذن، تحديث `medicalCheckDone` تلقائيًا.
- **الصلاحيات/الخصوصية:** وفق ADR-004؛ لا تُعرض التشخيصات في الجداول العامة.
- **القبول:** AT-023…025.

### بطاقة 4 — الأرقام الرسمية والمراسلات (REQ-017, 030)
- **المشكلة:** كتب Word بأعداد يدوية متضاربة.
- **سير:** اختيار قالب ← تعبئة حقول من الأرقام الرسمية ← معاينة ← اعتماد ← PDF مرقّم ← حفظ في الصادر.
- **القواعد:** رقم ثابت لا يُعاد؛ الكتاب المعتمد غير قابل للتعديل (نسخة جديدة).
- **القبول:** AT-017, 030.

### بطاقة 5 — التبادل مع الهيئة بـExcel (REQ-018/019/020)
- **المشكلة:** إدخال مزدوج ونقل يدوي لأرقام الغرف.
- **سير:** رفع الملف ← مطابقة الأعمدة (قالب محفوظ) ← معاينة أخطاء وفروقات ← تأكيد ← تطبيق مع إمكانية التراجع.
- **المفتاح:** الرقم الوطني ثم رقم الجواز.
- **المخاطر:** تغير صيغة الهيئة → قوالب قابلة للضبط.
- **القبول:** AT-018…020.

### بطاقة 6 — المواسم (REQ-031/032)
- **سير:** إنشاء موسم ← عمل ← إقفال (قفل كتابة) ← تقرير ختامي ← أرشفة.
- **ترحيل:** موسم 1447 يُنشأ من البيانات الحالية.
- **القبول:** AT-031/032.

### بطاقة 7 — الإعلام (REQ-040…044، مرحلة 4)
- **سير:** `DRAFT → REVIEWED → APPROVED → SCHEDULED → PUBLISHED | REJECTED`.
- **الأدوار:** مراسل (مشرف)، مسؤول أخبار، مشرف عام إعلام، مصمم، ناشر.
- **القبول:** AT-040.
